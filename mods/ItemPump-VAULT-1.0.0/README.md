# Item Pump (Scrap Mechanic Survival)

Moves items through **small pipes**: chest (IN / +Y) → Item Pump → chest (OUT / -Y).

- New craftable part (does **not** modify Vacuum / Pneumatic Pump)
- Does **not** change Item Filter script
- Optional filter slots on the pump (empty = move everything)

## Install (Vortex)

1. Copy folder `ItemPump-VAULT-1.0.0` into Vortex Scrap Mechanic mods staging
2. Enable **Item Pump** in Vortex (keep Item Filter enabled)
3. Deploy / relaunch game via Vortex
4. Craft at Craftbot → search "Item Pump" or "pump"

## Use

1. Orient pump: **IN** toward source chest, **OUT** toward destination chest
2. Connect with small pipes (same pipes as Item Filter)
3. Optional: put filter items in the pump (E)
4. Items transfer automatically
